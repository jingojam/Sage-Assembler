# SageAMD64 Assembler
## About
* SageAMD64 is a student-led passion project.
## Details
* SageAMD64 is an AMD64 assembler that parses assembly code from a source program file (`.asm`), and generates an executable program.
## Scope of the Project
* SageAMD64 adheres to the encoding specifications documented in AMD64 Technology, AMD64 Architecture Programmer's Manual Volumes 1-5 (Publication No. 40332, Revision 1.0, July 2026). Furthermore, future iterations of SageAMD64 aims support ELF64 (Linux) and PE (Windows) Executable Formats.
* SageAMD64 assumes an assembly source code format inspired by Intel-style syntax, which is commonly used in large assemblers such as Netwide Assembler (NASM).
* Additionally, since SageAMD64 only supports encoding formats for AMD64, it only supports the Windows x64, and System V AMD64 Application Binary Interfaces.
